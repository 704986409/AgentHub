# V0.5.3D — Production Trust Boundary / Internal Test Seam Closure

Baseline: `1d033cee8410c147f639f46a453c38cb7918c729` (`0.5.3C`).

## Result

- `GitWorktreeManagerOptions` no longer accepts a command evidence runner. The supported manager API always reaches the real `TaskCommandRunner` for Build/Test execution.
- `TaskCommandRunner.run()` accepts only the command specification and owns the environment snapshot and digest before its first await.
- Caller-supplied environment snapshots, fake command results and cleanup outcomes are absent from the workspace and root public barrels.
- Deterministic cleanup-failure coverage uses a deep-imported internal harness that is not exported from either production barrel.
- Concurrent evidence for the same task always returns `GIT_WORKTREE_OPERATION_BUSY`; evidence requests no longer join across potentially different ambient environments.
- Sequential executions under safe environment values A and B produce different `executionEnvironmentSha256` and `evidenceSha256` values without exposing names or values.
- Process-lifetime quarantine remains strongly held and survives transient coordinator replacement and manager reopen. There is no public force-clear operation.
- Canonical change capture, Git source visibility, worktree lifecycle, review/merge behavior, runtime/providers, database and migrations are unchanged. Real model calls: 0.
