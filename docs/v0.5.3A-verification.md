## Scope notes

All Git evidence calls use no-fetch/no-replace protection and bind source visibility to the evidence digest without exposing local paths, configuration values, or metadata contents. The command runner validates and owns a single execution snapshot, applies hard output/preview/timeout bounds, and treats unverifiable process cleanup as infrastructure failure rather than a successful command result.

No runtime/provider, database, migration, or real-model-call changes were made. V0.5.4 work was not started. Remote CI rows are intentionally pending until the commit and tag are pushed.
