## Continuous-writer limitation

V0.5.3 guarantees a stable, authoritative source capture immediately before and after every command. It does not provide transactional read-only isolation against a malicious process that changes source and restores it before exit. A hard read-only filesystem sandbox belongs to a later security stage.
