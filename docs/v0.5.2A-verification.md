# V0.5.2A — Canonical ChangeSet Identity / Git Diff Configuration Isolation

Baseline: `2be95d3422d480949172be84b52c2961409658c1` (`0.5.2`).

## Root-cause closure

Tracked change source identity is now an explicit allowlist of path, status, old/new
modes, and old/new object IDs. Git-derived presentation fields (`binary`, line counts,
and patch text) remain available in the returned structured inventory but are excluded
from `changeSetSha256`. Working-file, untracked, conflict-stage, and gitlink identities
remain included. A digest version marker is included in the canonical source.

All capture-time diff commands pin Myers diff, disable the indent heuristic, and pin
patch context/inter-hunk context and `a/`/`b/` prefixes. `GIT_DIFF_OPTS` is removed from
the child Git environment so inherited configuration cannot override the requested
presentation behavior.
