# V0.5.3C — Quarantine Durability / Evidence Environment Join Identity / Mandatory Regression Closure

Baseline: `0f0af7696b16c35f72748b8b3e70ea1d68d08193` (`0.5.3B`).

## Result

- Cleanup quarantine is held by a strong process-lifetime map keyed by the existing canonical repository identity and normalized task identity.
- Weak references and their finalizer own only transient operation coordination. Replacing that coordinator cannot clear quarantine.
- Capture, remove, evidence and create all reject a quarantined repository/task pair after repository reopen.
- Other tasks in the same repository and the same task ID in another repository remain available.
- Evidence requests snapshot every command's complete safe child environment at request entry. The exact snapshots drive both the operation join key and actual process spawn.
- Default safe variables, including `PATH`, and requested inherited values affect join identity. Only SHA-256 identities enter the join key and evidence structure.
- Environment identity is stable across object insertion order and follows Windows environment-key casing semantics.
- Tracked and self-ignored `.gitignore` files are enumerated separately and joined without truncation. Parent directories are checked before open, after open and after read.
- No review, merge, branch deletion, runtime/provider, database or migration behavior was added. Real model calls: 0.
