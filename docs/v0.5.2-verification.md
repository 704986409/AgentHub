## API and evidence contract

Use `manager.captureWorkspaceChanges(taskId, options?)`. The manager owns the runner,
trusted workspace inspection and the same repository/task operation fence as create/remove.
Equivalent option snapshots join the exact promise, incompatible concurrent operations reject.

Evidence separates durable base→HEAD, HEAD→index, index→worktree, untracked fingerprints,
conflict stages and ignored diagnostics. `workingFiles` contains raw SHA-256 fingerprints;
clean changed gitlinks carry their nested HEAD OID because Git's unstaged raw OID is zero.
Dirty submodules and incomplete index flags reject capture. No recursive submodule inventory.

Two complete passes compare identity, status, index stages/flags, all source metadata,
working bytes, ignored reports and optional patches. Every returned object/array is frozen.
The source digest excludes absolute paths, ignored outputs and patch presentation options.
Canonical ordering uses explicit JavaScript string comparison and sorted object keys.
Two observed equal passes are not an operating-system transaction or a lock on external writers.

Defaults: 20,000 changed paths, 1 GiB filesystem bytes per pass, 512 KiB total returned patch
text, 1,000 ignored path samples. Ignored count means Git-reported entries, possibly directories.
Runner structured-output overflow fails closed. Patch-only overflow preserves the inventory
and returns `omitted-limit`. Patches stay in returned memory; there is no event or DB integration.
Unrepresentable UTF-8 paths, unsafe Windows paths, special files and nested untracked repositories
fail safely. Symlink hashes cover link target bytes, never target file content.

Capture uses `--no-optional-locks`, disables fsmonitor, external diff, textconv, color and rename
heuristics, and disables object replacement and lazy fetching. Git supporting `--no-lazy-fetch`
is required (documented in [Git 2.45](https://git-scm.com/docs/git/2.45.0)); the exact guarded
`--version` invocation preflights capability before source collection. There is no fallback that
permits network access. The delivery review extended the same guard to trusted workspace identity
inspection and ancestry checks, which run before both source passes. Verified locally on Windows;
GitHub Actions results are recorded after publication.
